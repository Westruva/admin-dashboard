# Admin Dashboard

A responsive, component-style admin dashboard interface built with plain HTML and CSS.

This project focuses on clean layout composition, reusable UI patterns, and modern dashboard styling without using JavaScript frameworks.

## Project Overview

The dashboard is organized into three primary regions:

- Sidebar navigation with icon-based menu items
- Header area with search, profile summary, and action buttons
- Main content split into a projects grid and a widgets sidebar

The right sidebar includes:

- Announcements in a stacked card layout
- Trending profiles with inline avatar SVGs and aligned text

## Features

- CSS Grid-based page structure for two-dimensional layout control
- Flexbox for alignment inside cards, rows, and control groups
- Reusable project cards with icon action controls
- Inline SVG icons and avatars for sharp, scalable visuals
- Consistent spacing, card shadows, and rounded surfaces for a polished UI
- Accessibility-minded labels on action buttons

## Tech Stack

- HTML5
- CSS3
- Inline SVG graphics
- Google Fonts

## Folder Structure

- index.html: Dashboard markup and UI content
- style.css: Global reset, layout system, typography, and component styling

## Running the Project

Because this is a static project, no build step is required.

1. Clone or download the repository.
2. Open the project folder in your editor.
3. Open index.html in a browser.

## Learning Goals

This project is useful for practicing:

- CSS Grid and Flexbox together in one interface
- Card-based dashboard design patterns
- Visual hierarchy and layout spacing
- Working with SVG assets in UI components

## Future Improvements

- Add responsive breakpoints for tablets and smaller mobile screens
- Replace placeholder text with real project and announcement data
